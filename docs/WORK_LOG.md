## Multi-head Transformer and encoder-decoder extension

- User requested multi-head attention, an encoder-decoder, executable examples, tests and didactic docs. Wrote the new behavioral contracts first; confirmed CS1739/CS1061 for missing head configuration/inspection and CS0246 for the missing encoder-decoder type before implementation.
- Replaced duplicated encoder attention with shared full-width Q/K/V projections split into configurable heads, scaled by sqrt(head width), concatenated and output-projected. Preserved single-head constructor source calls, default head count and parameter ordering. Added per-head inspection and independent known-score/concatenated-output checks.
- Added TransformerSequenceToSequence: one encoder block, one decoder block, causal decoder self-attention, cross-attention over encoder memory, positionwise FFNs, residuals and learned normalization. Added typed source/decoder APIs and unmasked packed IGradientNetwork compatibility. Source/target lengths and feature dimensions may differ.
- Added copied, per-call trailing-padding masks; padded keys are excluded before softmax, padded feature projections are bypassed, padded outputs are zero and their loss is omitted. Nonempty prefixes ensure every causal query has a visible key. The shared trainer accepts forward functions/output masks without mutable mask context and retains transactional updates.
- Added teacher-forced training with shifted decoder inputs and free-running Generate(source, BOS), which feeds back continuous predictions without true targets. The two-head reversal task learned all four two-bit training sequences: mean teacher-forced loss 0.237203 to 0.000033 after 1500 epochs; free-running outputs passed the 0.2 acceptance tolerance. The separate two-head encoder example reduced mean loss from 0.129052 to 0.000021.
